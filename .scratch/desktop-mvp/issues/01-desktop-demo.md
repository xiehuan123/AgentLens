# 01 — 桌面应用与 SQLite 演示回放

Status: 可交给代理

Blocked by: 无，可立即开始

## 要实现的行为

按已确认的前端原型，在 Rust + Tauri 桌面应用中打开合成会话，通过 SQLite 读取时间线与步骤详情。

前端交互依据已确认的 [可点击原型](../prototype/index.html)。

## 验收条件

- [ ] 打开桌面应用可切换两种明确标识的演示会话，查看失败步骤、原样错误输出和补丁。
- [ ] 演示数据使用独立 SQLite 数据库，重复载入和重开应用不会生成重复步骤，不接触真实日志。
- [ ] 数据库位于本机应用数据目录，初始化和版本迁移可重复执行。
