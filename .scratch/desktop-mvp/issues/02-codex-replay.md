# 02 — 回放 Codex 本地会话

Status: 可交给代理

Blocked by: 01

## 要实现的行为

发现并只读导入 Codex 会话，通过 SQLite 浏览会话及对应工具步骤。

## 验收条件

- [ ] 从默认日志位置发现会话，列表按最近活动排序，可按项目和来源筛选，归档会话有标识。
- [ ] 按日志顺序渲染按轮次折叠的时间线，调用与结果归入同卡，命令、参数、输出、补丁和可见消息按原样展示。
- [ ] 结果缺失和明确失败分别按规格显示。未知事件展示可获取的类型和时间，数据库省略内部推理与加密字段。
- [ ] 同一日志重复扫描后步骤不重复。退出再启动可从 SQLite 回放已导入的记录。
