# AgentLens 桌面 MVP

## 目标

在 macOS 上跟看和回放本机 Codex 与 Claude Code 会话，顺着日志记录找到失败工具、相关修改及后续重试。桌面应用采用 Rust 和 Tauri，交付可在本机打开的 .app。

## 会话发现与跟看

- 扫描 Codex 与 Claude Code 的默认日志位置，支持环境变量配置和用户手动选择日志目录。只读对应的日志文件。Codex 归档会话在列表中标明归档。
- 会话按最近活动排序，可按项目和来源筛选。会话列表持续更新，选中的会话保持固定。首版显示一个会话的时间线，切换回来时续接新记录。
- 打开会话先加载历史记录，再追加已经写入的完整日志记录。仅当视图停在底部时自动滚动。往上翻时保持位置，显示新增步骤数，可一键回到最新位置。
- 没有新增记录时显示暂无新记录。应用以日志写入时间和日志事件为准。

## 步骤与排错

- 消息和工具步骤按日志顺序展示，长时间线可按任务轮次折叠。一条工具调用占一张卡片，配对的结果更新同一张卡片。
- 已记录调用且轮次尚无明确结束事件时，缺少结果显示「等待结果」。轮次明确结束且依然缺少结果时显示「未记录结果」。只有明确的失败证据才标记失败。
- 支持筛选失败步骤、跳到失败前最近一笔已有记录的修改，以及按路径查看该文件在本轮的相关步骤。相关步骤按时间线呈现，由用户判断因果。
- 对显式文件工具、补丁和结构化事件展示可读取的文件操作，区分发起修改和日志确认的结果。普通命令展示日志保存的调用、工作目录、输出和退出码。缺失字段显示未知，已知截断明确标注。
- 主时间线显示子代理派发。日志明确关联时可展开子会话，关联缺失的子会话可独立打开。

## 内容与用量

- 展开步骤时，原样显示日志已保存的命令、参数、输出和补丁。日志中的用户可见消息也原样显示。不做脱敏。未知事件显示可读取的类型和时间。省略内部推理内容和加密字段。
- 日志全程本机只读，默认不上传。演示模式使用独立的合成样本，界面明确标识。
- 会话侧栏展示日志实际记录的 token 用量及统计范围，未知值明确标注。Codex 优先采用新版累计快照，缺失时回退到旧版。Claude Code 按消息 ID 去重，分别展示普通输入、缓存读取、缓存写入和输出。

## 本地存储

- 使用 SQLite 保存一份已解析的数据，包括会话索引、时间线、步骤详情、文件操作、用量记录与导入进度。源日志保持只读，应用重启可从本机数据库回放已导入的内容，并继续读取新增记录。
- 步骤详情以用户确认的原样展示范围入库，不做脱敏。数据库留在本机应用数据目录，演示数据与真实会话存储隔离。
- 导入记录和进度在同一事务提交。同一日志重复读取或中断后续读不得生成重复记录，未写完整的记录等写完再导入。

## 验收

- 分别用 Codex 和 Claude Code 执行「读文件 → 修改 → 运行失败 → 修复 → 重跑成功」。完整日志记录写入后，已打开的时间线在 2 秒内更新，并把工具结果归入对应步骤。
- 关闭并重新打开同一会话，能回放相同记录顺序并定位同一个失败。从失败卡片可查命令、错误输出和此前的修改。
- 演示模式可独立复现上述流程。解析测试覆盖两种日志、调用结果配对、缺失或未写完记录、原样详情、重复用量和未知字段。
- 在本机验证应用构建与 .app 启动。提供英文 README、中文使用文档及开发启动和打包命令。
