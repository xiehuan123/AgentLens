## 验证记录

- 使用临时 SQLite 核对 36 份真实 Codex 日志，最近一次测试发现 170 项本机技能、3 条明确选择、17 条候选证据、49 条 MCP 调用和 5 个 MCP 配置。样本随本机最近修改的会话变化。
- 全量索引测试处理 131 个本地日志源，共 20 批，约 11 秒，解析异常为 0。再次索引处理的文件数量为 0。
- 自动化测试覆盖同名技能、资源变化和版本去重、删除保留、目录符号链接、异常目录、近期与项目过滤、截断 JSONL、并行 MCP、相同日志副本、幂等回放、未知类型、失败状态、忽略工具发现及配置敏感字段。
- 在浏览器预览中使用专用测试夹具验证仪表盘、Skills 内容、MCP 列表、反馈保存及回到会话。正式应用通过本地 SQLite 读取真实数据。
- 17 项常规 Rust 测试和 2 项真实环境测试通过。完成前端语法检查、差异检查和 macOS 调试包构建。

## 已知限制与后续任务

- 本机日志尚未验证到能可靠识别 Agent 自主选择的证据。缺少明确触发信息或历史版本时保留未知。同轮重复选择只能按已验证的保守口径聚合。
- 当前默认索引未压缩的 Codex 与 Claude Code 会话。原始历史里未保留的记录、其它 Agent 的专有证据以及 MCP 实际运行状态需要未来的适配器。
- 本地技能清单包含可访问插件缓存和本地兼容目录。它反映文件发现范围，无法确认所有运行时插件和启用状态。技能更新采用周期扫描，快照限制为最多约 4 MiB UTF-8 资源和 200 个文件。过大的资源、部分文件类型及资源符号链接可能无法进入快照。
- 分析页只展示无敏感值的 MCP 配置和调用结构。原始参数及结果通过证据入口跳回已有会话查看。
- 图表日期按 UTC 聚合。当前 macOS 调试包做了本机构建，Windows 打包由现有发布流程负责。
- 下一阶段可为经过验证的自主选择信号增加独立适配器，并扩展历史压缩日志、插件运行时状态和人工评估流程。
