如何开启 Codex Trace

从该终端启动新的 Codex CLI 会话。旧会话不会补录，正在运行的桌面会话不会切换设置。

macOS
CODEX_ROLLOUT_TRACE_ROOT="$HOME/agentlens-traces" codex
Windows PowerShell
$env:CODEX_ROLLOUT_TRACE_ROOT = Join-Path $HOME 'agentlens-traces'
codex

选择生成的会话子目录。生成 state.json 时，请使用录制该包的同一个 Codex 可执行文件。

原始请求可能含有提示词、代码和工具数据，只在本机按需读取。
